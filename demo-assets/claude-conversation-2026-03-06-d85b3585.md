### Key design decisions

- Every flow starts with `clearState: true` so each test runs independently from a fresh state
- `optional: true` on assertions prevents flows from crashing if elements are conditionally rendered (guest vs authenticated)

- Theme flows visit every screen to catch theme-specific rendering bugs
- Subflows (`dismiss_onboarding`, `login_as_guest`) are reused to keep flows DRY
