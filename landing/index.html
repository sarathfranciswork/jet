Integration

Native GitHub Integration

Bidirectional sync between GitHub and Jet. Issues, PRs, comments — everything stays in sync automatically.

  • Bidirectional issue sync with label-based triggers
  • PR automation — [JET-123] in PR titles maps to issue states
  • @claude AI agent picks up issues and delivers working PRs
GitHub ↔ Jet Sync
$ gh issue create --label "jet-sync"
Creating issue in repo...
✓ Issue #142 created on GitHub
→ Synced to Jet · Sprint 12
$ @claude pick up JET-142
Claude analyzing issue...
✓ PR #87 opened · 3 files changed
→ Jet status: In Review
